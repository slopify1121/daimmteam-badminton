# Daimmteam Badminton Club - Official Website & Portal Pendaftaran

## 💻 Cara Menjalankan Website Secara Lokal

1. Buka terminal di folder project ini:
   ```bash
   npm run dev
   ```
2. Buka URL yang tampil di terminal (biasanya `http://localhost:5173`) pada browser Anda.

---

## 🛠️ Build & Deploy

- **Build untuk Production:**
  ```bash
  npm run build
  ```
  File statis siap tayang akan berada di folder `dist/`.
- File website dapat diunggah ke hosting cPanel, Vercel, Netlify, atau GitHub Pages secara instan.
